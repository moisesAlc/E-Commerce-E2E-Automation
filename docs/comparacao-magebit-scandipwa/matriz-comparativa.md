## Notas de leitura da matriz

1. Nesta sessão a **home** dos dois ambientes respondeu HTTP 200; a diferença crítica comprovada está no **fluxo UI pós–Add to Cart**, na rota **`/collections` (404)** e em **um 502** no checkout ScandiPWA.  
2. Afirmações do tipo “sempre 502” **não** se aplicam a esta sessão para a home — o 502 foi comprovado pontualmente no checkout.  
3. Automação Cypress do repositório **não** foi usada como prova desta matriz.
